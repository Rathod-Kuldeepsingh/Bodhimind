## 📦 Installation & Setup

```bash
# 1️⃣ Clone the repo
git clone https://github.com/Rathod-Kuldeepsingh/Bodhimind.git
cd Bodhimind

# 2️⃣ Install dependencies
flutter pub get

# 3️⃣ Run the app
flutter run


Bodhimind/
├── lib/                # Flutter app source code
│   ├── screens/        # UI Screens
│   ├── widgets/        # Custom widgets
│   └── main.dart       # Entry point
├── assets/             # Images, icons
├── android/ios/        # Native platform folders
├── pubspec.yaml        # Dependencies and metadata
└── firebase.json       # Firebase configuration
